MATRIXLAB LUXE - UPDATED LAYOUT

This package contains two 3x3 matrix operation programs:
1. matrix_numpy_luxe.py       (requires NumPy and CustomTkinter)
2. matrix_without_numpy_luxe.py (requires CustomTkinter only)

Install GUI dependency:
  python -m pip install customtkinter

For NumPy version also install:
  python -m pip install numpy

Run GUI:
  python matrix_numpy_luxe.py
  python matrix_without_numpy_luxe.py

Run command-line mode:
  python matrix_numpy_luxe.py cmd
  python matrix_without_numpy_luxe.py cmd

Layout update: smaller matrix input cards and a taller, fully visible result area.
